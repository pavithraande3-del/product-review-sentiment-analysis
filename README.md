# Product Review Sentiment Analysis

## Overview
A Data Science project that classifies customer product reviews into Positive, Neutral, and Negative sentiments using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP and TF-IDF
- Logistic Regression
- Power BI

## Project Workflow
1. Load and explore the review dataset.
2. Clean and preprocess review text.
3. Convert text into numerical features using TF-IDF.
4. Train a Logistic Regression model.
5. Predict sentiment for product reviews.
6. Visualize insights using Power BI.

## Model Performance
The balanced Logistic Regression model achieved approximately 87.08% test accuracy.

## Dashboard Features
- Customer sentiment distribution
- Rating distribution (1–5 stars)
- Reviews by product category
- Sentiment summary cards

** Project Files**

Product_Review_Sentiment_Analysis.ipynb — model training and analysis

product review sentiment analysis.pbix — Power BI dashboard


## Dataset

This project uses the **Datafiniti Consumer Reviews of Amazon Products** dataset from Kaggle.

- **Source:** [Kaggle – Datafiniti Amazon Consumer Reviews](https://www.kaggle.com/datasets/datafiniti/consumer-reviews-of-amazon-products)
- **Processing:** Cleaned review text and converted product ratings into Positive, Neutral, and Negative sentiment labels.
- **Output:** Sentiment predictions and visualizations generated using Python, NLP, and Machine Learning.
