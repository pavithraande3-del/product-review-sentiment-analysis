# Product Review Sentiment Analysis

## Overview
A Data Science project that classifies customer product reviews into Positive, Neutral, and Negative sentiments using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP and TF-IDF
- Logistic Regression
- Power BI

## Project Workflow
1. Load and explore the review dataset.
2. Clean and preprocess review text.
3. Convert text into numerical features using TF-IDF.
4. Train a Logistic Regression model.
5. Predict sentiment for product reviews.
6. Visualize insights using Power BI.

## Model Performance
The balanced Logistic Regression model achieved approximately 87.08% test accuracy.

## Dashboard Features
- Customer sentiment distribution
- Rating distribution (1–5 stars)
- Reviews by product category
- Sentiment summary cards

## Dataset
Datafiniti Consumer Reviews of Amazon Products (May 2019), sourced from Kaggle. Refer to the original dataset page for licensing and sharing terms.
